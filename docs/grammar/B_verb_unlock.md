# Bundle B — Verb Unlock (Lessons 4–7)

The bundle where Spanish stops being vocabulary and starts being **sentences**. You get
your first helper verbs (*quiero, intento, voy a*), a rule that hands you ~1000 verbs for
free, and the little pronouns (*me, te, lo*) that hook onto the end of a verb.

Everything here is built from four moving parts that you snap together:

```
[ subject ]   [ helper ]   [ verb (to-form) ]   [ pronoun ]
   yo          quiero          cancelar             lo
 (optional)   (optional)      (the action)      (glued to end)
```

> **Grammar terms** appear in *(italics)* next to the plain label, e.g. **to-form verb**
> *(infinitive)*. Plain label first so it reads like Mad Libs; the real term is there when
> you want it. **Slots** are written in `[brackets]` — fill them in.

---

## 1. Word groups

Words sorted by **the job they do in a sentence**, not by dictionary order. Drill the group, not the word.

### Helper verbs *(main verb + infinitive; `voy a` = periphrastic future auxiliary)* — start the sentence, mean "I ___"
| Spanish | English | note |
|---------|---------|------|
| `quiero`   | I want        | |
| `intento`  | I try / I'm trying | one form covers both English meanings |
| `voy a`    | I'm going to  | the only helper that carries an `a` (see §2, S4) |

All end in **`-o` = "I"**. That `-o` is the whole reason they mean *I*.

### Object pronouns *(object pronouns: `lo/los` = direct object · `me` = reflexive · `te` = object "you")* — glue onto the **end** of a to-form verb *(infinitive)*
| Spanish | English | example |
|---------|---------|---------|
| `me` | me / myself     | prepararme  (get myself ready) |
| `te` | you (informal)  | obligarte   (oblige you) |
| `lo` | it / him        | cancelarlo  (cancel it) |
| `los`| them            | verlos      (see them) |

`lo → los` is just **+s** for plural. English hides this ("him" vs "them"); Spanish keeps it regular.

### Motion verbs *(verbs of motion)* — these pull in an `a` before the next verb
| Spanish | English |
|---------|---------|
| `voy`   | I go / I'm going |
| `pasar` | to pass / pass by |

Why care: a motion verb *moving toward* another action wants `a` between them (§2, S5).

### Subject pronoun *(subject pronoun)* — emphasis only
| Spanish | English | when |
|---------|---------|------|
| `yo` | I | **only** when stressing *who* — "*I* want." Otherwise drop it; `-o` already says "I". |

### Little words
| Spanish | English | term |
|---------|---------|------|
| `no`   | not (goes in front, like English) | negation |
| `pero` | but  | conjunction |
| `ahora`| now  | adverb |
| `a`    | to (direction) | preposition |
| `con`  | with | preposition |

## The word factory (free verbs) — the big rule of this bundle

Not a sentence structure, but it fills the `[verb]` slot for almost every drill below.

```
English  -tion word   →   Spanish -ción noun   →   drop -ción, add -r   →   verb
 cancellation              cancelación               cancelar               (to cancel)
 preparation               preparación               preparar               (to prepare)
 confirmation              confirmación              confirmar              (to confirm)
```

Bonus ending: English **-ence / -ance → -encia / -ancia** (experience → *experiencia*).
Go the **long way** through the noun every time — it stops you inventing fake verbs.

## 2. Sentence structures (drill these)

Each structure: a **shape** line (the only "code"), the slots you can swap, worked examples, then a **Drill** the student finishes out loud or on paper.

---

### S1 — "I want to ___" / "I'm trying to ___" *(main verb + infinitive)*
**shape:** `[helper] + [verb-toform]`  *(conjugated verb + infinitive)*

- helper: `quiero` · `intento`
- verb: `cancelar` · `preparar` · `celebrar` · `confirmar` · `visitar`

```
quiero preparar     I want to prepare
quiero celebrar     I want to celebrate
intento confirmar   I'm trying to confirm
```

**Drill (EN → ES):** I want to cancel · I want to participate · I'm trying to celebrate · I want to visit

---

### S2 — Make it negative: "I don't want to ___" *(negation)*
**shape:** `no + [helper] + [verb-toform]`

`no` sits in front, exactly like English. Nothing else moves.

```
no quiero            I don't want
no quiero cancelar   I don't want to cancel
no intento imitar    I'm not trying to imitate
```

**Drill:** I don't want to prepare · I'm not trying to confirm · I don't want to visit

---

### S3 — Hook a pronoun on the end: "I want to ___ it / you / myself" *(enclitic object pronoun)*
**shape:** `[helper] + [verb-toform]+[pronoun]`  *(infinitive + enclitic pronoun)*

The pronoun **fuses to the end** of the to-form verb *(infinitive)* — this attached form is
an **enclitic**. One written word.

| build | result | English |
|-------|--------|---------|
| quiero + cancelar + lo | `quiero cancelarlo`  | I want to cancel it |
| quiero + preparar + me | `quiero prepararme`  | I want to get (myself) ready |
| no quiero + obligar + te | `no quiero obligarte` | I don't want to oblige you |
| quiero + salvar + lo   | `quiero salvarlo`    | I want to save him |

**Drill:** I want to publish it · I'm trying to imitate him · I don't want to provoke you · I want to inform myself

---

### S4 — "I'm going to ___"  (the near future) *(periphrastic future: ir a + infinitive)*
**shape:** `voy a + [verb-toform](+[pronoun])`

Works just like English "I'm going to eat." The `a` is **not optional** — `voy` is a verb of motion (§2, S5).

```
voy a cancelar      I'm going to cancel
voy a verlos        I'm going to see them
voy a confirmarlo   I'm going to confirm it
```

**Drill:** I'm going to prepare · I'm going to visit you · I'm going to cancel it · I'm going to see them

---

### S5 — Chaining verbs, and the motion-`a` rule *(serial verbs; verb of motion + a + infinitive)*
**shape:** `[helper] (a?) [verb] (a?) [verb] ...`

Rule: **a motion verb glues to the next verb with `a`. A non-motion verb does not.**

| sentence | English | why the a's |
|----------|---------|-------------|
| `voy a verlos` | I'm going to see them | `voy` is motion → `a` |
| `quiero verlos` | I want to see them | `quiero` not motion → **no** `a` |
| `voy a intentar verlos` | I'm going to try to see them | `voy`→`a`; `intentar` not motion → no `a` |
| `voy a pasar a visitarte` | I'm going to pass by to visit you | `voy`→`a`; `pasar` **is** motion → another `a` |

**Drill:** I want to see them · I'm going to see them · I'm going to try to cancel it · I'm going to pass by to visit you

---

### S6 — Add emphasis with `yo` *(overt subject pronoun for contrast)*
**shape:** `yo + [sentence]`

Only when you want to stress **who**. Word order matches English: `yo no quiero`, never *no yo quiero*.

```
quiero        I want         (neutral)
yo quiero     *I* want       (…not you)
yo no quiero  *I* don't want
```

**Drill:** *I* want to cancel · *I* don't want to · *I'm* going to visit

---

## 3. Same idea, said other ways

- **"I love you"** → `te quiero` (everyday, friends/family/lovers, literally "I want you") vs `te amo` (heavy, serious). Same English, two strengths.
- **`intento`** = "I try" **and** "I'm trying." Spanish doesn't split simple vs continuous here.
- **`voy`** = "I go" **and** "I'm going." Same.
- **A verb's to-form is reusable:** the `cancelar` in `quiero cancelar` is the exact same word as in `voy a cancelar` — only the helper in front changes the tense/meaning.

---

## 4. Emphasis & bends

- **Drop the subject.** `-o` already means "I", so `yo` is for stress only. This is the default for every sentence above — `quiero`, not `yo quiero`, unless you're contrasting.
- **Pronoun lives on the verb's tail.** `verlos`, `cancelarlo`, `prepararme`, `obligarte` — always the **to-form** verb in this bundle, never the helper. (A pronoun can later also float to the front; that arrives in a later bundle.)
- **Motion = `a`.** The single thing to internalize from S4–S5: `voy`/`pasar` reach toward the next action through `a`; `quiero`/`intento` grab it directly.
- **`lo → los`:** plural is regular `+s`. Don't let English's irregular "him/them" fool you.

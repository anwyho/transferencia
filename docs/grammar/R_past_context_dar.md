# Bundle R — Past in context + dar past + L-L fix (Lessons 61–63)

The bundle where the two past tenses stop living apart and start sharing a sentence:
**"I was cooking when the phone rang."** One verb sets the scene (the line), the other
drops the event (the point). You also get *dar* (the one verb that breaks the point-past
rule), the sound-fix that turns *le lo* into *se lo*, and more mind-flip practice with
*gustar* / *parecer*.

Everything here is built from three moving parts you already half-know:

```
[ line in past ]      [ when ]      [ point in past ]
  cocinaba             cuando         sonó
 (was -ing, scene)   (the hinge)    (one shot, event)
```

> **Grammar terms** appear in *(italics)* next to the plain label, e.g. **line in the past**
> *(imperfect)*. Plain label first so it reads like Mad Libs; the real term is there when
> you want it. **Slots** are written in `[brackets]` — fill them in.

---

## 1. Word groups

Words sorted by **the job they do in a sentence**, not by dictionary order. Drill the group, not the word.

### Scene-setting verbs *(imperfect; the "line in the past")* — was ___-ing, ongoing background
| Spanish | English | note |
|---------|---------|------|
| `cocinaba` | I was cooking | `-aba` (from `cocinar`) |
| `hablaba`  | I was talking | `-aba` (from `hablar`) |
| `me parecía` | it was seeming to me | `-ía` (from `parecer`) |
| `me gustaba` | I wasn't / was liking it | `-ía` family (from `gustar`) |

Line = the **`-aba` / `-ía`** endings. It's the running background, not a single moment.

### Event verbs *(preterite; the "point in the past")* — one shot, it happened
| Spanish | English | note |
|---------|---------|------|
| `sonó`   | it sounded / rang | `-ó` (from `sonar`) |
| `llegó`  | he/she arrived    | `-ó` (from `llegar`) |
| `llegué` | I arrived         | `-é`; the `gu` keeps the hard /g/ before `é` |
| `lo vi`  | I saw it          | one-shot event |
| `me gustó` | I liked it      | it pleased me, once |
| `me pareció` | it seemed to me | one moment of seeming |

Point = the **`-é/-ó`** (and `-í/-ió`) endings. Verb-then-subject is often more natural:
`sonó el teléfono`, `llegó María`.

### `dar` in the point-past *(preterite; irregular endings)* — the rule-breaker
| Spanish | English | note |
|---------|---------|------|
| `di`    | I gave        | no accent — short word |
| `dio`   | he/she/you-formal gave | no accent — one syllable |
| `dimos` | we gave       | |

`dar` is **`-ar`** but borrows the **`-er/-ir`** point-past endings (see §1.5).

### Reflexive-style verbs ending in `-se` *(pronominal verbs)* — the `se` must become *your* pronoun
| Spanish | English | the pronoun changes |
|---------|---------|---------------------|
| `quedarse` | to stay | `me quedé` · `se quedó` · `nos quedamos` |
| `acordarse` | to remember | `me acuerdo` · `nos acordamos` |

Never leave the `-se` parked. It shifts to `me` / `te` / `se` / `nos` to match the subject.

### Object pronouns *(indirect + direct object pronouns)* — stack before the verb: indirect, then direct
| Spanish | English | role |
|---------|---------|------|
| `me` / `nos` / `te` | (to) me / us / you | indirect (the receiver) |
| `lo` / `los` | it / them (masc) | direct (the thing) |
| `la` / `las` | it / them (fem)  | direct (the thing) |
| `le` / `les` | (to) him/her/you-formal / them | indirect — **becomes `se` before `lo/la`** (§1.6) |

### Mind-flip verbs *(verbs that take an indirect object: "it pleases me")* — subject and object swap vs English
| Spanish | English (flipped) | English (natural) |
|---------|-------------------|-------------------|
| `me gusta` | it pleases me | I like it |
| `le gusta` | it is pleasing to him/her/you-formal | he/she likes it |
| `me parece` | it seems to me | I think |

Always say the **mid road** out loud — "it pleases him" — then the structure can't trip you.

### Little words
| Spanish | English | term |
|---------|---------|------|
| `cuando` | when (the hinge between line and point) | conjunction |
| `por`    | by / for / through (`por teléfono` = by phone) | preposition |
| `a`      | to (and the clarifying tag, §1.6) | preposition |
| `pero`   | but | conjunction |
| `si` / `o` | if / or | conjunction |
| `todavía` | yet | adverb |
| `algo`   | something | pronoun |
| `bien`   | well / good | adverb |

## 1.5 `dar` in the point-past — the one rule-breaker

Not a sentence structure, but it loads the verb slot in every "I gave it" drill below.

```
dar is an -ar verb …            but in the point-past it takes -er/-ir endings:
  normal -ar point-past:  -é / -ó / -amos      (e.g. llegué / llegó / llegamos)
  dar instead:            di  / dio / dimos     (no accents — they're short)
```

Build the **verb first**. If you want *te lo di* ("I gave you it"), your first thought is
*"I gave" = di* — then the pronouns flow on. Don't try to assemble all the bits at once.

---

## 1.6 The L-L fix and the clarifying `a`

```
le + lo  →  se lo        Spanish hates two /l/ sounds in a row.
les + lo →  se lo        le/les + lo/la/los/las  ALL collapse to se + (lo/la/los/las).
le + los →  se los
```

This `se` is a **pure sound fix** — it does NOT mean "himself/herself" (that's a different
`se`). Because `se lo` could mean *to him / her / them / you-formal*, it's **ambiguous**, so
you clarify with **`a` + person** tacked on the end: `se lo di a él` / `a ella` / `a ellos`.

**With the clarifying `a`, you ALWAYS repeat the little word.** `Le di algo a él` — `le`
stays even though you said `a él`. Other prepositions don't repeat: `lo compré para ti`
(no second pronoun). The `a` is special — it flexes between "to / for / from", so the
repetition keeps it clear.

## 2. Sentence structures (drill these)

Each structure: a **shape** line (the only "code"), the slots you can swap, worked examples, then a **Drill** the student finishes out loud or on paper.

---

### S1 — "I was ___-ing when ___ happened" *(imperfect + preterite contrast)*
**shape:** `[line-verb] + cuando + [point-verb]`  *(imperfect, then preterite)*

The heart of the bundle. **Line** = the scene that was already running (`-aba`/`-ía`).
**Point** = the single event that interrupts it (`-é/-ó`). `cuando` is the hinge.

- line: `cocinaba` · `hablaba por teléfono`
- point: `sonó (el teléfono)` · `llegó (María)`

```
Cocinaba cuando el teléfono sonó.        I was cooking when the phone rang.
Cocinaba cuando sonó el teléfono.        (same — verb-then-subject is often more natural)
Hablaba por teléfono cuando María llegó. I was talking on the phone when Maria arrived.
Hablaba por teléfono cuando llegó María. (same, verb first)
```

**Drill (EN → ES):** I was cooking when Maria arrived · I was talking on the phone when it rang · I was cooking when the phone rang

---

### S2 — Line vs point, same verb: feeling that *was* vs feeling that *happened* *(imperfect vs preterite of one verb)*
**shape:** `[mind-flip verb -ía] … pero cuando [point], [mind-flip verb -ó]`

Same verb, two tenses, two meanings. `-ía` = the ongoing impression; `-ó` = the verdict
at one moment. English barely marks this, so lean on the Spanish structure, not the translation.

| line (ongoing) | point (one moment) |
|----------------|--------------------|
| `me parecía bien` — it was seeming fine | `me pareció bien` — it seemed fine (then) |
| `no me gustaba` — I wasn't liking it | `no me gustó` — I didn't like it |

```
Me parecía bien, pero cuando lo vi, no me gustó.
  It was seeming fine, but when I saw it, I didn't like it.
Me parece bien.        It seems good to me.       (present, for contrast)
Me pareció bien.       It seemed good to me.      (point)
Me parecía bien.       It was seeming good to me. (line)
```

**Drill:** It was seeming fine, but when I saw it I didn't like it · It seemed good to me · I wasn't liking it

---

### S3 — `-se` verbs in the past: change the `se` to match *(pronominal verb, conjugated)*
**shape:** `[matching pronoun] + [verb stem + past ending]`

The dictionary `-se` is a placeholder. Swap it for the pronoun that matches the subject —
`me` / `se` / `nos` — then conjugate the verb normally.

| build | result | English |
|-------|--------|---------|
| quedarse + I | `me quedé` | I stayed |
| quedarse + he | `se quedó` | he stayed |
| quedarse + we | `nos quedamos` | we stayed |
| acordarse + I | `me acuerdo` | I remember |
| acordarse + we | `nos acordamos` | we remember |

**Drill:** I stayed · he stayed · we stayed · I don't remember · we don't remember

---

### S4 — "I gave it to him": build the verb, then stack pronouns *(preterite + object pronouns)*
**shape:** `([no]) [indirect] + [direct] + [verb]`  *(indirect-direct-verb order)*

Verb first in your head (§1.5), then the pronouns clip on in front, **indirect then direct**.

```
Lo di.              I gave it.
Me lo dio.          He gave me it.
Nos lo dio.         He gave us it.
No nos lo dio.      He didn't give us it.
Te lo di.           I gave you it.
Lo vendí. / Se lo vendí.   I sold it. / I sold it to him.
```

**Drill:** I gave it · he gave me it · he didn't give us it · I gave you it · I sold it

---

### S5 — The L-L fix step by step: `le lo` → `se lo` (+ clarify with `a`) *(the se substitution)*
**shape:** `se + [lo/la/los/las] + [verb] (+ a [person])`

Watch the substitution happen, then add the clarifying tag — and **repeat the pronoun**.

| you mean | would be | becomes (L-L fix) | clarified |
|----------|----------|-------------------|-----------|
| I gave it to him | ~~le lo di~~ | `se lo di` | `se lo di a él` |
| I gave it to her | ~~le lo di~~ | `se lo di` | `se lo di a ella` |
| I sold it to him | ~~le lo vendí~~ | `se lo vendí` | `se lo vendí a él` |
| I sold them (fem) to her | ~~les las vendí~~ | `se las vendí` | `se las vendí a ella` |
| He sent it to them | ~~le lo envió~~ | `se lo envió` | `se lo envió a ellos` |

```
Se lo di.                      I gave it to him/her/them/you-formal. (ambiguous)
Se lo di a él.                 I gave it to him.
Le di algo a él.               I gave him something. (le repeats with the a!)
Se las vendí a ella.           I sold them (fem) to her.
Él se lo envió a ella.         He sent it to her.
No se lo envió a ustedes todavía.  He didn't send it to you guys yet.
```

**Drill:** I gave it to him · I gave it to her (clarify) · I sold them (fem) to her · he sent it to them · I gave him something (with *a él*)

---

### S6 — Mind-flip in the third person: `le gusta`, clarified with `a` *(indirect object + clarifying a)*
**shape:** `(a [person]) + le + gusta/gustó (+ a [person])`

`le gusta` = "it is pleasing to him/her/you-formal/it" — same `le` ambiguity as S5, so
clarify with `a` (front or back). Without the `a`, *ella le gusta* flips to "she is
pleasing to (someone)" — the `a` is what pins the direction.

```
Le gusta.            He/she/you-formal likes it. (lit. it is pleasing to ___)
Le gusta a ella.     She likes it.
A ella le gusta.     She likes it. (clarification up front)
Le gustó.            He/she liked it.
Le gustó a ella.     She liked it.
```

**Drill:** she likes it (clarify two ways) · he likes it · she liked it · you-formal likes it

---

### S7 — Tie it together: remember-if-I-gave-it *(pronominal verb + embedded clause + L-L fix)*
**shape:** `([no]) [pronoun] acord… + si + se lo [verb] + a [person] (o a [person])`

Real sentences stack everything: a `-se` verb (S3), an embedded `si` clause, the L-L fix,
and clarifying `a`s with `o`.

```
No me acuerdo si se lo di a él o a ella.
  I don't remember if I gave it to him or her.
No nos acordamos si se lo dimos a él o a ellas.
  We don't remember if we gave it to him or to them (fem).
No sé si se lo envié.
  I don't know if I sent it to him.
```

**Drill:** I don't remember if I gave it to him or her · we don't remember if we gave it to them (fem) · I don't know if I sent it to him

## 3. Same idea, said other ways

- **Line vs point, same fact.** `No me gustaba` and `No me gustó` can both translate "I didn't
  like it." The choice is your **mental framing** — ongoing feeling (line) vs one verdict
  (point) — not a different fact.
- **Word order is flexible around `cuando`.** `Cocinaba cuando sonó el teléfono` =
  `Cocinaba cuando el teléfono sonó`. Verb-then-subject (`sonó el teléfono`) is often the
  more natural ring.
- **`se lo` is ambiguous on purpose.** It covers *to him / her / them / you-formal* all at
  once; the `a él` / `a ella` tag is how you disambiguate when it matters.
- **Two `se`'s, same spelling.** The `se` in `se lo di` (sound fix) is NOT the `se` in
  `se quedó` (the reflexive/pronominal one). Same letters, different jobs.
- **Mind-flip mid-step.** Translate `le gustó` as "it pleased him" first, *then* render
  natural English. The mid road stops the subject/object swap from biting you.

---

## 4. Emphasis & bends

- **Line sets the stage, point lights the match.** When two pasts meet, ask "which was
  already running?" → that one is `-aba`/`-ía`. "Which dropped in one shot?" → that one is
  `-é/-ó`. `cuando` usually sits between them.
- **Build the verb first.** For `te lo di`, think *di* ("I gave") before anything else.
  `dar`'s short, accent-free point-past (`di` / `dio` / `dimos`) is the rule-breaker to memorize.
- **`le/les + lo/la/los/las` always collapses to `se`.** No exceptions — Spanish refuses the
  double /l/. The meaning is unchanged; only the sound is fixed.
- **Repeat with `a`, don't repeat with `para`.** `Le di algo a él` (repeat `le`) but
  `lo compré para ti` (no repeat). The clarifying `a` is the special case.
- **Keep the `se` visible on `-se` verbs.** `me quedé`, `se quedó`, `nos acordamos` — it
  changes to match the subject; dropping it breaks the verb.
- **Stressed `o` splits to `ue`.** `acordarse` → `me acuerdo` (stress on the `o` → `ue`) but
  `nos acordamos` (stress elsewhere → `o` stays).

- `llamar` family — to call / the phone / to call oneself / name — reused around `el teléfono`.

- `pero` (but), `todavía` (yet), `para mí / para ti / para usted` (for me/you) — and the
  front-loaded `no` for negation, all carried in from earlier bundles.

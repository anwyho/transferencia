# Bundle C — Helpers + saber + first I-form (Lessons 8–10)

This bundle gives you a second helper verb (*debo*), a third-person form (*quiere*), the
verb *saber* for stitching long sentences, and the rule that lets you build the **I-form**
of almost any verb yourself. You also meet **gendered words** (*la/las*) and the *tener*
("-tain") family.

Everything still snaps together from the same parts as Bundle B — you just get more pieces
for each slot:

```
[ subject ]   [ helper ]   [ verb (to-form) ]   [ pronoun ]
   yo          debo            identificar          la
 (optional)   (optional)      (the action)      (glued to end)
```

> **Grammar terms** appear in *(italics)* next to the plain label, e.g. **to-form verb**
> *(infinitive)*. Plain label first so it reads like Mad Libs; the real term is there when
> you want it. **Slots** are written in `[brackets]` — fill them in.

---

## 1. Word groups

Words sorted by **the job they do in a sentence**, not by dictionary order. Drill the group, not the word.

### Helper verbs *(main verb + infinitive)* — start the sentence
| Spanish | English | note |
|---------|---------|------|
| `quiero`  | I want          | `-o` = "I" |
| `quiere`  | he/she/it wants, you (formal) want | `-e` = "he/she/it/you-formal" — same band as `es` |
| `debo`    | I owe / I must  | use it like "must": *debo continuar* |
| `intento` | I try / I'm trying | one form, both English meanings |
| `voy a`   | I'm going to    | the helper that carries an `a` (Bundle B, S4) |

`quiero → quiere` is the whole conjugation move this bundle: swap **`-o` (I)** for **`-e`
(he/she/it/you-formal)**. The verb form alone tells you the subject — no separate "he"/"she".

### Articles "the" *(definite articles)* — sit in front of a noun, must match its gender
| Spanish | English | example |
|---------|---------|---------|
| `la`  | the (feminine)        | `la casa` (the house) |
| `las` | the (feminine plural) | `las casas` |
| `lo`  | (the, masc. — same word as the pronoun) | |
| `los` | (masc. plural) | |

### Object pronouns *(object pronouns)* — glue onto the **end** of a to-form verb *(infinitive)*
| Spanish | English | example |
|---------|---------|---------|
| `me` | me / myself        | `visitarme` (visit me) |
| `te` | you (informal)     | `explicarte` (explain to you) |
| `lo` | him / it / you (formal, masc) | `identificarlo` |
| `la` | her / it (fem) / you (formal, fem) | `verla` |
| `los`| them (masculine)   | `identificarlos` |
| `las`| them (feminine)    | `identificarlas` |

Plural is always **+s**: `lo → los`, `la → las`. English's irregular "him/them" hides this; Spanish keeps it regular.

### Verb *saber* and the question words
| Spanish | English | note |
|---------|---------|------|
| `saber`  | to know | memory hook: British "savvy" (Latin *sapere*); spelled `b`, English kept /v/ |
| `por qué`| why (also "because") | two words, accent on the `é` |
| `porque` | because | same word, written together |

### Little words
| Spanish | English | term |
|---------|---------|------|
| `sí`    | yes (with accent) | adverb |
| `si`    | if (no accent)    | conjunction |
| `pero`  | but | conjunction |
| `ahora` | now | adverb |
| `mañana`| tomorrow / morning | adverb |
| `más`   | more (related to "massive"); `más tarde` = later | adverb |
| `a`     | to (direction) | preposition |
| `con`   | with | preposition |
| `algo`  | something | pronoun |

## The I-form factory — chop the `-r`, add `-o`

The big rule of this bundle. Every "to"-form verb ends in **`-r`** — one of three flavors
**`-ar` / `-er` / `-ir`** (*separar*, *saber*, *venir*). To make the **"I" form**:

```
to-form (infinitive)   →   chop -ar/-er/-ir   →   add -o   →   "I" form
 intentar                   intent-               intento     (I try)
 donar                      don-                  dono        (I donate)
 comer                      com-                  como        (I eat)
 crear                      cre-                  creo        (I create / I believe)
 organizar                  organiz-              organizo    (I organize)
```

**Stress the second-to-last syllable:** *inTENto*, not *intenTO*. Stressing the final `-o`
accidentally makes it past tense ("he tried") — that comes later.

**Irregulars exist.** `voy` (I'm going) doesn't end in `-o` at all.

### The *tener* "-tain" family — `-tain` → `-tener`
*Tener* = "to have," and it also lives inside English **-tain** verbs. Swap **-tain → -tener**:

| English | Spanish |
|---------|---------|
| contain    | `contener` |
| obtain     | `obtener` |
| maintain   | `mantener` |
| sustain    | `sostener` (note `sus- → sos-`) |
| entertain  | `entretener` |

### The `-go` irregular family — I-form pops in a `g`
A little family that all break the same way in the I-form:

| verb | expected | actual |
|------|----------|--------|
| `tener` (to have) | *teno* | `tengo` (I have) |
| `venir` (to come) | *veno* | `vengo` (I come) |

### One spelling exception
"Explanation" is **`explicación`**, not *explanación* → verb **`explicar`** (to explain).
English keeps the root in *inexplicable*.

## 2. Sentence structures (drill these)

Each structure: a **shape** line (the only "code"), the slots you can swap, worked examples, then a **Drill** the student finishes out loud or on paper.

---

### S1 — "He/she/you-formal wants to ___" *(third-person main verb + infinitive)*
**shape:** `quiere + [verb-toform](+[pronoun])`

Same as `quiero`, but `-e` shifts the subject to **he/she/it/you-formal**. Context (or a `yo`/name elsewhere) decides which.

```
quiere saber        he/she wants to know
quiere visitarme    he/she/you-formal wants to visit me
quiere iniciarlo    he/she wants to start it
```

**Drill (EN → ES):** he wants to know · she wants to visit me · you (formal) want to start it

---

### S2 — Match the article and pronoun to gender *(grammatical gender; definite article + noun)*
**shape:** `la/las + [noun]` · or pronoun `la/las` on a verb's tail

Gender lives on the **word**, not the object. Feminine words usually end in `-a`. Feminine
`la` (the/her/it), plural `las`.

| build | result | English |
|-------|--------|---------|
| la + casa | `la casa` | the house |
| quiero + ver + la | `quiero verla` | I want to see it (fem) / her |
| debo + identificar + la | `debo identificarla` | I must identify it (fem) |
| debo + identificar + las | `debo identificarlas` | I must identify them (fem) |

**Drill:** the house · I want to see her · I must identify them (fem) · I must identify it (masc)

---

### S3 — Ask a question: just raise your voice *(yes/no question by intonation)*
**shape:** `¿[statement]?`

No "do"/"does" needed. In writing, an upside-down `¿` opens the question. Negative works the same.

```
¿Quiere visitarme?       Do you want to visit me?
¿No quiere visitarme?    Don't you want to visit me?
¿Por qué no quiere visitarme?   Why don't you want to visit me?
```

**Drill:** Do you want to come? · Don't you want to know? · Why doesn't he want to let me know?

---

### S4 — "I must ___" with `debo` *(modal verb + infinitive)*
**shape:** `debo + [verb-toform](+[pronoun])`

`debo` slots in exactly where `quiero` does. Use it like English "must."

```
debo continuar      I must continue
debo identificarlo  I must identify it / him
debo identificarlos I must identify them (masc)
```

**Drill:** I must continue · I must identify it (fem) · I must identify them (fem)

---

### S5 — Stitch long sentences with `si` and `por qué` *(subordinate clauses)*
**shape:** `[clause] + (si / por qué) + [clause]`

Build block by block; once a chunk is said, drop it from your head and move to the next.

| sentence | English |
|----------|---------|
| `Quiero saber si quiere saber.` | I want to know if you want to know. |
| `Quiero saber si quiere invitarme.` | I want to know if he/she wants to invite me. |
| `¿Por qué no quiere saber?` | Why doesn't he/she want to know? |
| `Quiero saber por qué no quiere saber.` | I want to know why he/she doesn't want to know. |

**Drill:** I want to know if you want to know · I want to know if she wants to invite me · I want to know why he doesn't want to know

---

### S6 — The motion-`a` rule, stacked *(verb of motion + a + infinitive)*
**shape:** `[clause] ... venir/voy (a) [noun-place] (a) [verb] ...`

Motion verbs (`voy`, `venir`) take an `a` before a following verb **and** before a place. They stack.

| sentence | English | the a's |
|----------|---------|---------|
| `¿Quiere venir a la casa?` | Do you want to come to the house? | `venir`→`a la casa` |
| `Quiere venir a la casa a visitarme.` | She wants to come to the house to visit me. | one `a` = "to the house," one `a` = "to visit me" |
| `Quiero saber por qué no quiere venir a la casa a visitarme.` | I want to know why she doesn't want to come to the house to visit me. | stack it slowly |

**Drill:** Do you want to come to the house? · She wants to come to the house to visit me · I want to know why she doesn't want to come to visit me

---

### S7 — Build the present "I" form and use it *(present tense, first person)*
**shape:** `[I-form verb] (+ [time word] / [con + person])`

Chop `-r`, add `-o`. With a future-time word (`mañana`, `más tarde`) the plain present is fine for the future.

```
no dono              I don't donate / I'm not donating
como mañana          I'm eating tomorrow
como con Pablo mañana  I'm eating with Pablo tomorrow
vengo mañana         I'm coming tomorrow (irregular -go)
tengo                I have (irregular -go)
```

**Drill:** I organize · I create · I'm eating tomorrow · I'm coming tomorrow · I'm eating with Pablo

---

### S8 — `tener` + "-tain," want/going-to have it *(tener family; periphrastic future)*
**shape:** `[helper] + (con)tener(+[pronoun])` · or `voy a + tener...`

```
quiero tenerlo          I want to have it
voy a tenerlo           I'm going to have it
voy a tenerlo más tarde I'm going to have it later
```

**Drill:** I want to have it · I'm going to have it · I'm going to have it later · I want to contain it

## 3. Same idea, said other ways

- **No "to" needed for the listener:** Spanish lets you "explain you something" directly — `quiero explicarte algo` = "I want to explain something to you" (literally "explain-you something").
- **`más tarde`** = "later," literally "more late." Build the idea from the parts you have.
- **Plain present = near future:** `como mañana` and `voy a comer mañana` both say "I'm eating tomorrow." With a time word, you don't even need a helper.
- **`saber` vs the I-form:** the to-form `saber` in `quiero saber` is the exact same word everywhere — only the helper in front changes the meaning.
- **`quiero` and `quiere`** are the same verb; only the ending swaps the subject. The whole conjugation is in that final letter.

---

## 4. Emphasis & bends

- **The ending carries the subject.** `-o` = I, `-e` = he/she/it/you-formal. Drop the pronoun; the verb already says who.
- **Gender is on the word, not the thing.** Don't think "the house is feminine" — think "the *word casa* is feminine." That's why `la` and `-la` must match it.
- **Formal vs informal "you" is regional.** Formal = `lo/la`, informal = `te`. Spain often starts formal with strangers; Argentina rarely uses formal (it can sound sarcastic). Safe default: start formal, then mirror locals.
- **Pronoun still lives on the verb's tail.** `verla`, `identificarlas`, `explicarte`, `tenerlo` — always the to-form verb in this bundle.
- **Recall is a feeling, not a fact.** If you panic over a word, it hides. Relax, ask "what was that related to?", and let it surface. Confidence first — try to say things you think you can't.
- **Stress matters in the I-form.** `inTENto` (I try, present) vs `intenTÓ` (past) — keep the loud part on the second-to-last syllable.

## Carried-in lexicon (from earlier bundles)

- `quiero` / `intento` / `voy a` — helper verbs and the "I'm going to ___" pattern (Bundle B, S1–S4).
- `me` / `te` / `lo` / `los` — object pronouns gluing onto a to-form verb (Bundle B, S3; extended here with `la`/`las`).
- The **motion-`a` rule** — `voy`/`pasar` reach toward the next action through `a` (Bundle B, S5); `venir` joins the motion family here.
- The **`-ción → -ar` word factory** — *identificación → identificar*, *imaginación → imaginar*, *justificación → justificar* (Bundle B). The exception *explicación → explicar* lives here.
- `no + verb` front-loaded negation, and `es` "is" banding subjects together (Bundle A) — the same banding logic now powers `quiere`.
- /kh/ (j) sound in *justificar*; /th/ for Spanish `z` in *organizo* (Spain) — pronunciation threads from Bundle A.

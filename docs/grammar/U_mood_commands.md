# Bundle U — Mood Triggers + Commands (Lessons 71–73)

The bundle where the mood tense *(subjunctive)* stops being a curiosity and becomes a tool.
You bolt it onto **trigger phrases** (*espero que*, *me gusta que*), you turn it into **orders**
(*no hables*, *coma*, *cállate*), and you fire it after *cuando* when the event hasn't happened yet.

Everything here runs on one decision: **is the situation a fact, or is it subjective / unreal /
not-yet?** Facts take the normal present. The rest flip into the mood tense.

```
[ trigger / setup ]   [ que? ]   [ verb in MOOD tense ]   [ little word ]
  espero / me gusta      que          cuentes / vea          (me, lo, te...)
  command (no setup)      —           coma / cállate         (glued to end if +)
```

> **Grammar terms** appear in *(italics)* next to the plain label, e.g. **mood tense**
> *(subjunctive)*. Plain label first so it reads like Mad Libs; the real term is there when
> you want it. **Slots** are written in `[brackets]` — fill them in.

## 1. Word groups

Words sorted by **the job they do in a sentence**, not by dictionary order. Drill the group, not the word.

### Subjunctive triggers *(subjunctive-triggering matrix clauses)* — a subjective/wishing phrase + `que`, then the verb flips to mood tense
| Spanish | English | note |
|---------|---------|------|
| `espero que` | I hope that      | hoping isn't a fact → mood tense |
| `me gusta que` | I like that    | a reaction/opinion → mood tense |
| `quiero que`  | I want that / I want (someone) to | a wish → mood tense |

The `que` is the hinge: once you say it, the next verb is mood tense, not normal present.

### Splits verb *contar* *(o → ue stem-changing verb; double meaning)* — counts AND tells
| Spanish | English | example |
|---------|---------|---------|
| `contar` | to count / to recount, tell | *cuento* = I tell · *un cuento* = a story |
| `contar con` | to count **on** (lit. "count with") | *cuenta conmigo* = count on me |

Spanish says "count **with**" where English says "count **on**". The `con` is built in.

### Personal *a* *(personal a; preposition `a` + el = al)* — mark a specific person who is being acted **on**
| Spanish | English | example |
|---------|---------|---------|
| `a` (before a person) | (no translation) | *espero que vean a María* = I hope they see María |
| `al` (= `a` + `el`)   | to the (m.) | *quiero que vea al hombre* = I want him to see the man |

Word order is flexible, so the `a` shows **who is on the receiving end**. `a` + `el` always
written as one word `al`. Already a preposition like `con`? Then **no** extra personal `a`
(*contar con María*). Only for **specific** people — *find the plumber* (the one) gets `a`,
*find a plumber* (any) doesn't.

### Irregular mood-tense roots *(irregular subjunctive stems)* — built off the *I* form, not the *they* form
| verb | mood-tense root | full set |
|------|-----------------|----------|
| `ver` (to see) | `vea` (from *veo*) | vea · veas · vea · vean — keep the `e`, else *van* would collide with "they go" |
| `ir` (to go)   | `vaya` | vaya · vayas · vaya · vayamos · vayan |

### Little words *(clitic object / reflexive pronouns)* — before the verb normally; glue to the **end** of a positive command
| Spanish | English | term |
|---------|---------|------|
| `me` | me / myself | object / reflexive |
| `te` | you (informal) / yourself | object / reflexive |
| `lo / la` | it / him / her | direct object |
| `los` | them | direct object |
| `se` | (to) him/her/them; oneself | indirect (was *le*) / reflexive |
| `nos` | us / ourselves | object / reflexive |

`le → se` still applies before `lo/la`: *no **se** lo des* = don't give it to him.

### Little setup words
| Spanish | English | term |
|---------|---------|------|
| `no`   | not / don't (goes in front) | negation |
| `que`  | that / let… | conjunction |
| `cuando` | when | conjunction |
| `ya`   | already / now | adverb |
| `conmigo` | with me | preposition + pronoun |
| `juntos / juntas` | together (m./f.) | adjective (agrees) |

## Commands: the imperative rule of this bundle

Not a sentence structure, but it governs §2's S3–S5. **Almost every command is the mood tense.**
The single shortcut is the positive informal one.

```
                          POSITIVE              NEGATIVE
informal (tú)        drop -s off tú form     mood tense
                     compra · cómelo         no compres · no lo comas
formal (usted)       mood tense              mood tense
                     compre · coma           no compre · no coma
plural (ustedes)     mood tense              mood tense
                     compren · coman         no compren · no coman
let's (nosotros)     mood tense -emos        mood tense
                     esperemos               no esperemos
```

- **Only positive informal is special:** take the *tú* present form, chop the final `-s`.
  *compras → compra*, *comes → come*. (Looks like he/she form — tone + attached words make it clear.)
- **Everything else is mood tense:** all negatives, all formal, all plural, and "let's".
- **Little words attach to the END of a positive command**, written as one word: *cómpralo*,
  *espérenme*, *cállate*. The end-attachment is an extra ear-clue that it's an order.
- **Negative commands keep little words BEFORE the verb** (normal position): *no lo compres*,
  *no te olvides*, *no los esperen*.
- **Attaching shifts the stress, so a written accent appears:** *compra* → *cómpralo*,
  *esperen* → *espérenme*, *olvida* → *olvídate*. Be exact with these.

### `cuando` + future = mood tense

`cuando` already carries the future flavor, so Spanish uses **present, not future tense** after
it — but if the event **hasn't happened yet**, it flips to the mood tense (Spanish is
"superstitious" about treating an unhappened future as fact).

- General truth → normal present: *cuando hablamos* = when we (generally) speak.
- Future event → mood tense: *cuando hablemos* = when we (will) speak later.

## 2. Sentence structures (drill these)

Each structure: a **shape** line (the only "code"), the slots you can swap, worked examples, then a **Drill** the student finishes out loud or on paper.

---

### S1 — Trigger + `que` + mood tense *(subjunctive after a subjective matrix clause)*
**shape:** `[trigger] que [subject?] [verb-mood] ([personal a] [person])`

- trigger: `quiero` · `espero` · `me gusta`
- verb-mood: `cuentes` · `cuenten` · `vea` · `vean` · `visite` · `comprendas`

```
Quiero que me cuentes.            I want you to tell me.
Espero que cuentes conmigo.       I hope you count on me.
Esperamos que cuenten con María.  We hope they count on María.
Me gusta que la profesora visite. I like that the teacher visits.
```

**Drill (EN → ES):** I want you-all to tell me something · I hope you understand David · I like that he/she visits the teacher · We hope they tell it to María

---

### S2 — Personal `a` on the person being acted on *(personal a; a + el = al)*
**shape:** `[trigger] que [verb-mood] a [specific person]`

The `a` marks **who is on the receiving end**. Drop it and flexible word order makes the meaning flip.

| sentence | English | why the a |
|----------|---------|-----------|
| `Espero que vean a María` | I hope they see María | María is **seen** → personal `a` |
| `Espero que comprenda David` | I hope David understands | no `a` → David is the one understanding |
| `Quiero que vea al hombre` | I want him to see the man | `a` + `el` = `al` |
| `Me gusta que visite a la profesora` | I like that he/she visits the teacher | teacher is **visited** |

Already have `con`? No extra `a`: *Esperamos que cuenten con María*.

**Drill:** I hope you understand David · I want him to see the man · I like that he visits the teacher · We hope they see María

---

### S3 — Negative command (any flavor) *(negative imperative = subjunctive)*
**shape:** `no [little-word(s)] [verb-mood]`

All negatives are mood tense, little words stay **in front**. Watch the ending: *no te quedas*
(statement, "you don't stay") vs *no te quedes* (command, "don't stay!").

```
No hables.            Don't speak.
No te quedes.         Don't stay.
No lo des. / No se lo des a él.   Don't give it. / Don't give it to him.
No los esperen.       Don't wait for them. (you all)
No te olvides.        Don't forget.
```

**Drill:** Don't eat it (informal) · Don't sell it (informal) · Don't forget it (you all) · Don't wait for them

---

### S4 — Positive command + the end-attach rule *(positive imperative; enclitic pronouns)*
**shape:** `[verb-command]+[little word(s)]`  — accent shifts, written accent appears

Informal positive = drop `-s` off *tú* form. Everything else = mood tense. Little words **glue to the end**.

| build | result | English |
|-------|--------|---------|
| compra + lo | `cómpralo` | buy it (informal) |
| compra + me + lo | `cómpramelo` | buy it for me |
| come + lo | `cómelo` | eat it (informal) |
| esperen + me | `espérenme` | wait for me (you all) |
| coma + lo (formal) | `cómalo` | eat it (formal) |
| olvida + te | `olvídate` | forget (yourself) (informal) |
| calla + te | `cállate` | shut up (informal) |

**Drill (EN → ES):** buy it (informal) · eat it (formal) · wait for him (you all) · forget it (formal) · shut up (you all)

---

### The full command table — drill one verb across all five forms

`comer` (to eat), object `lo`:

| | positive | negative |
|--|----------|----------|
| informal (tú) | `cómelo` (drop -s, attach) | `no lo comas` (mood, front) |
| formal (usted)| `cómalo` (mood, attach) | `no lo coma` (mood, front) |
| plural (ustedes)| `cómanlo` (mood, attach) | `no lo coman` (mood, front) |
| let's (nosotros)| `comámoslo` (mood -emos) | `no lo comamos` (mood, front) |

The flip is mechanical: **positive → attach to end**, **negative → little word jumps in front**.

---

### S5 — "Let's" and "let him/her" commands *(hortatory & third-person imperative)*
**shape (let's):** `(no) [verb -emos]`  ·  **shape (let him):** `que [verb-mood]`

- "Let's" = the *nosotros* mood form (`-ar` verbs end `-emos`). Tone can soften it to "shall we?"
- "Let him/her/them" = `que` + mood tense.

```
Esperemos.            Let's wait.        (¿Esperemos? = shall we wait?)
No esperemos.         Let's not wait.
Que espere.           Let him wait.
Que termine ya.       Let it finish already.
Que se calle.         Let him shut up.
```

**Drill:** Let's wait · Let's not forget it · Let it finish already · Let him shut up

---

### S6 — `cuando` + future flips to mood tense *(temporal clause; future event → subjunctive)*
**shape:** `cuando [verb-mood], [main clause in present]`

Spanish keeps the future in **present tense** after `cuando` — but an unhappened event flips
to mood tense. The verb of `ir` is irregular: `vaya, vayas, vayamos, vayan`.

| sentence | English | which tense |
|----------|---------|-------------|
| `Cuando hablamos` | when we speak (generally) | normal present — a habit |
| `Cuando hablemos` | when we speak (later) | mood — not yet happened |
| `Cuando comamos juntos, hablamos` | when we eat together, we'll speak | mood after *cuando*, present main |
| `La vemos cuando vamos` | we see her when we go (generally) | normal present |
| `La vemos cuando vayamos` | we'll see her when we go (future) | mood (`vayamos`) |

**Drill:** when we speak (later) · we'll see her when we go (future) · when we eat together, we'll speak · when we speak (generally)

## 3. Same idea, said other ways

- **`contar` = "count" and "tell".** *Cuento* = I count / I tell; *un cuento* = a story. Same verb, two everyday meanings.
- **`contar con` = "count on".** Spanish uses "with"; English uses "on". *Cuenta conmigo* = count on me.
- **`ahí` and `allí`** both mean "there" — barely any difference. *No te quedes ahí / allí.*
- **`olvidar` doesn't like to be alone:** name what's forgotten (*olvídalo*) or go reflexive (*olvídate*). Bare *olvida* is rare.
- **Word order is free** because the personal `a` / mood ending carry the meaning: *me gusta que la profesora visite* = *me gusta que visite la profesora*.
- **Same command, two tenses:** *cómelo* (positive informal, drop-s) vs *no lo comas* (negative, mood) — the ending alone signals the flip.

---

## 4. Emphasis & bends

- **The mood-tense flip is the whole bundle.** Subjective trigger + `que` → mood. Any command except positive-informal → mood. `cuando` + not-yet event → mood. Facts and habits stay in plain present.
- **Positive = tail, negative = front.** The single placement rule for little words: glue them to the end of a positive command (*cómpralo*, *espérenme*), bounce them to the front for a negative (*no lo compres*).
- **Accents track the stress.** Attaching a pronoun pushes the stress back, so the written accent surfaces: *compra → cómpralo*, *esperen → espérenme*, *olvida → olvídate*. Don't drop them.
- **Personal `a` only for specific people** (and personified pets / death — *escapar a la muerte*). *A* plumber: none. *The* plumber: yes.
- **Build irregular moods off the *I* form.** *ver → veo → vea* (keep the `e`); *ir → vaya*. The *they*-form route would collide with other verbs.

## Carried-in lexicon (from earlier bundles)

- **Mood tense (subjunctive)** itself — formation after *quiero, necesito, prefiero, espero, gusta* (Lessons 69–70). This bundle adds the command and `cuando` uses.
- **Little-word placement** *(me, lo, la, se)* — normally before the verb; flipped to **after** for positive commands (earlier reflexive + object-pronoun bundles).
- **`le → se` before `lo/la`** — still applies inside negatives: *no se lo des* (earlier indirect-pronoun bundle).
- **Reflexive verbs** *quedarse, olvidarse, callarse* — supply the `te/se/nos` that rides these commands.
- **Written accents** — the stress-shift rule reused every time a pronoun attaches (*espérenme, cómpralo, olvídate*).
- **`conmigo / contigo`** and **o-splits verbs** (*contar → cuento*) from earlier lessons.

# Bundle A — Foundation: vowels, es / no es, convertible words (Lessons 1–3)

The starting line. No grammar to memorize yet — instead you learn that **Spanish is
modern Latin**, so thousands of English words are already Spanish in disguise. You get the
5 pure vowel sounds, the one-word verb `es` ("is"), and three conversion rules that hand
you a free vocabulary the moment you learn them.

Everything in this bundle is built from one tiny machine:

```
[ word ]      es / no es      [ describing word ]
 (a thing)    ( "is" / "isn't" )    (a quality)
   Es             normal.
```

> **Grammar terms** appear in *(italics)* next to the plain label, e.g. **describing word**
> *(adjective)*. Plain label first so it reads like Mad Libs; the real term is there when
> you want it. **Slots** are written in `[brackets]` — fill them in.

---

## 1. Word groups

Words sorted by **the job they do in a sentence**, not by dictionary order. Drill the group, not the word.

### The verb *(verb "to be", `ser`, 3rd person)* — the engine of every sentence here
| Spanish | English | note |
|---------|---------|------|
| `es`    | is / he is / she is / it is / you are (formal) | one little word, several meanings |
| `no es` | is not / isn't | stick `no` in front; nothing else moves |

You don't need to say "he/she/it" — `es` alone covers it when context is clear.

### Describing words *(adjectives)* — fill the slot after `es`
| Spanish | English |
|---------|---------|
| `normal`     | normal |
| `legal` / `ilegal` | legal / illegal (one `l`) |
| `natural`    | natural |
| `liberal`    | liberal |
| `ideal`      | ideal |
| `importante` | important |
| `diferente`  | different |
| `original`   | original |
| `flexible` / `posible` / `probable` | flexible / possible / probable |

### Manner words *(adverbs)* — "in this manner"; can lead the sentence
| Spanish | English |
|---------|---------|
| `normalmente` | normally / usually |
| `naturalmente`| naturally / obviously |
| `realmente`   | really |
| `posiblemente`| possibly |

### Little words
| Spanish | English | term |
|---------|---------|------|
| `no` | no / not / don't (goes in front) | negation |

## The word factory (free vocabulary) — the big rule of this bundle

Not a sentence structure, but it fills the `[describing word]` slot for almost every drill below.
Three conversion rules turn English words into Spanish ones on sight:

```
ending in English        →   Spanish               →   examples
  -al                        same word                normal, legal, natural, ideal, cultural
  -ant / -ent                add -e → -ante / -ente   important→importante, different→diferente
  -ly                        → -mente (glued on)      constantly→constantemente, legally→legalmente
  -ible / -able              often same word          possible→posible, probable→probable, flexible→flexible
```

**Don't push it too hard.** "Doable" wouldn't convert — the `-able` isn't a real Latin root.
Some rules have exceptions; experiment, and feel free to be wrong. With pure vocabulary you
can guess freely (stick on `-o`, `-e`, or `-a` when there's no rule: *verb → verbo*). With
sentence structure, take your time.

## 2. Sentence structures (drill these)

This bundle has exactly one shape. That's honest — at this stage you're building the engine, not the car.

---

### S1 — "It is ___" / "It isn't ___" *(subject + verb `ser` + adjective)*
**shape:** `(no) es + [adjective]`

- adjective: `normal` · `legal` · `ideal` · `natural` · `importante` · `diferente` · `original`
- `no` sits in front, exactly like English. Nothing else moves.

```
Es normal.          It is normal.
Es legal.           It is legal.
No es natural.      It is not natural.
Es importante.      It's important.
No es diferente.    It's not different.
```

**Drill (EN → ES):** It is ideal · It isn't normal · It's important · It's not different · It is original

---

### S2 — Lead with a manner word *(sentence-initial adverb + `es` + adjective)*
**shape:** `[adverb] + es + [adjective]`

A manner word *(adverb)* can open the sentence, just like English "Normally it's…".

```
Normalmente es importante.      Normally / usually it's important.
Naturalmente es original.       Naturally / obviously it's original.
Posiblemente es original.       Possibly it's original.
```

**Drill (EN → ES):** Normally it's normal · Possibly it's important · Naturally it's legal

---

## 3. Same idea, said other ways

- **`es` is four English phrases at once** — "is", "he is", "she is", "it is", "you are (formal)".
  *Es liberal* can be "It's liberal" or "He/she is liberal"; context decides. You rarely need a subject word.
- **`normalmente`** = "normally" **and** "usually." Same word, like English "normally I do X" = "usually I do X."
- **`naturalmente`** = "naturally" **and** "obviously." One word covers both.
- **`real`** = "real" **and** "royal." *Real Madrid* = "Royal Madrid," not "real Madrid."

---

## 4. Emphasis & bends

- **Stress is part of the word.** English front-loads stress (NOR-mal); Spanish pushes it to
  the end (nor-MAL). For `-ante`/`-ente`/`-ible` words it lands on the second-to-last syllable
  (im-por-TAN-te, po-SI-ble). Don't memorize — just listen for where it falls.
- **5 pure vowels, always the same:** a /ah/, e /eh/, i /ee/, o /oh/, u /oo/. English vowels
  mush around; Spanish vowels never do. Spanish is phonetic — letters always make the same sound.
- **Say only what's written.** Cut English's hidden /y/: "ann-yu-al" → *anual*. The `s` is a
  real /s/, never /z/ — *es* = /es/, never /ez/.
- **English /j/ → Spanish /kh/** (throaty, friction in the throat). It's the *sound*, not the
  letter g: *general* /khe-ne-RAL/, *original* /o-ri-khi-NAL/, *digital* /di-khi-TAL/.
  Memory hook: *Argentina* — that's the sound.
- **An `r` at the start of a word is rolled,** like a little engine: *real, realmente.*
